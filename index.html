Setup Firebase for Real-Time Collaboration

1

Create a Firebase Project

Go to console.firebase.google.com
→ Click "Create a project" (or "Add project")
→ Name it anything, e.g. aion-cf-gantt
→ Disable Google Analytics (not needed) → Create

2

Register a Web App

In Firebase console → gear icon → "Project settings"
→ Scroll to "Your apps" → Click the </> (Web) icon
→ App nickname: gantt-editor → Click "Register app"
→ You'll see a code block with firebaseConfig = {...}
→ Copy the entire {...} block (just the curly braces part)

3

Paste Your Config

4

Create Realtime Database

Back in Firebase console → left sidebar → "Build" → "Realtime Database"
→ Click "Create Database" → Choose any location → Next
→ Select "Start in TEST MODE" → Enable
(Test mode allows open read/write for 30 days — fine for your project timeline)

5

You're All Set!

Click "Go Live" in the toolbar → Enter a room name (e.g. AION-2026) → Share the URL with partners.

Sharing options:
• GitHub Pages: Push this HTML to a repo, enable Pages → instant public URL
• Send the file: Email gantt_editor.html to partners — they open locally, click "Go Live" with the same room code, and edits sync via Firebase
